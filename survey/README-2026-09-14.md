# Erdős problem hunt — data and scripts (snapshot 14 Sep 2026)

- `openish.csv`   — the 632 unresolved problems (open / falsifiable / verifiable / decidable) from teorth/erdosproblems, with prize, tags, formalization.
- `ranked.csv`    — 572 unresolved, non-FrontierMath problems scored for "underexplored + elementary"; columns include comment/claim counts and the statement.
- `fme_list.txt`  — the 65 problems in FrontierMath Erdős (Bloom's hard list). Avoid.
- `ai_touched.txt`— the 405 problems with an AI-contributions wiki entry (wiki frozen 30 Jun 2026).
- `parse_pages.py`— parser for erdosproblems.com problem pages (expects a `pages/N.html` directory; fetch with a browser User-Agent, ~0.35 s between requests).
- `p151_atlas.py` — problem 151: exhaustive check over all graphs on <= 7 vertices (networkx atlas).
- `p151_exh.py`   — problem 151: exhaustive check for n = 9..12 using nauty `geng -D{h-1}` plus an independence-number filter. Needs `./nauty/geng` on the path.
- `p151_sa.py`, `p151_sa2.py` — problem 151: simulated annealing for counterexamples (the second version caps max degree at H(n)-1).
- `p151.py`       — problem 151: complements of Ramsey-extremal triangle-free graphs (all fail).

Result for problem 151: the conjecture tau(G) <= n - H(n) holds for every graph on at most 12 vertices.

## Problem 644 tools (added 14 Sep 2026, evening)

- `p644_sat.py k N1,N2 t1,t2` — exact search: is there a k-uniform family on N vertices with the (7,2)-property (every <=7 edges have a 2-point transversal) and tau >= t? CEGAR with pysat (`pip3 install python-sat`).
- `p644_cyc.py k N1,N2 t` — same, restricted to Z_N-invariant families (orbit variables); fast heuristic for lower-bound constructions.
- `p644_restricted.py r t` — size-restricted families {A : |A|=r, |A ∩ X| in R}: exact tau by an interval argument, (7,2) checked by SAT set cover.
- `fkw1999.txt` — text of Fon-Der-Flaass, Kostochka, Woodall, Discrete Math 207 (1999): f(r,7,2) <= ceil(7r/8), f(4m,7,2) >= 3m+1.
- `cmb1984.txt` — text of Colbourn, Phelps, Rödl, Canad. Math. Bull. 27 (1984) on block-size profiles (relevant to problem 734).

Results so far: f(2,7)=2; f(3,7)=3 on <=7 vertices; f(4,7)=3 on <=8 vertices (exhaustive); monotonicity f(k+1,7) >= f(k,7).
